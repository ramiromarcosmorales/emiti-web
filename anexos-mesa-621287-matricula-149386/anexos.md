# Anexo - "Frameworks & NodeJS"

## JavaScript: Frameworks y Herramientas

JS permite el desarrollo integral de aplicaciones web, ejecutandose tanto en el navegador web como en el servidor gracias al entorno **Node.js**. Para estandarizar el desarrollo, se utilizan stacks que agrupan tecnologías compatibles.

### Stack Tecnológicos

#### Stack MERN
* **Tecnologías:** MongoDB, Express, React, Node.js.
* **Características:** Utiliza React. Es flexible y está basado en componentes.

#### Stack MEAN
* **Tecnologías:** MongoDB, Express, Angular, Node.js.
* **Características:** Utiliza Angular. Es una solución robusta y estructurada que impone una arquitectura rígida ideal para grandes empresas.

## Frameworks elegidos

Para este proyecto se selecciona el **Stack MERN** por su flexibilidad de React para migrar al interfaz actual y la eficiencia de Express para centralizar la lógica.
