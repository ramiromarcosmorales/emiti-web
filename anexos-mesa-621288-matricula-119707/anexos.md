# Anexo – Frameworks & NodeJS

En el desarrollo de aplicaciones web modernas con JavaScript existen múltiples frameworks y herramientas que permiten mejorar la organización del código, la escalabilidad de los proyectos y la experiencia del usuario, lo que facilita el desarrollo del frontend y backend.

## Frameworks y herramientas de desarrollo con JavaScript

Un framework de JavaScript es una estructura predefinida que proporciona reglas, convenciones y utilidades para desarrollar aplicaciones web de manera más eficiente, siendo su principal objetivo evitar la repetición de código, mejorar la organización del proyecto y facilitar el mantenimiento a largo plazo.

Además de los frameworks, JavaScript se apoya en herramientas de entorno como Node.js, que permiten ejecutar código JavaScript fuera del navegador y construir aplicaciones completas del lado del servidor.

## Stacks tecnológicos: MERN y MEAN

Un stack es un conjunto de tecnologías que trabajan juntas para construir una aplicación web completa.

### Stack MERN

El stack MERN, se utiliza comúnmente para aplicaciones web modernas de tipo SPA (Single Page Application) y está compuesto por:

* MongoDB: base de datos NoSQL
* Express: framework backend sobre Node.js
* React: librería para la interfaz de usuario
* Node.js: entorno de ejecución del servidor

### Stack MEAN

La diferencia principal con el Stack Mern radica en el framewor de frontend usado y está compuesto por:

* MongoDB
* Express
* Angular
* Node.js

### MERN vs MEAN

| Característica | MERN | MEAN |
|---------------|------|------|
| Frontend | React | Angular |
| Complejidad | Media | Alta |
| Curva de aprendizaje | Media | Alta |
| Flexibilidad | Alta | Media |

En el contexto del proyecto Emití, MERN resulta más flexible y adaptable al enfoque actual del sistema.
